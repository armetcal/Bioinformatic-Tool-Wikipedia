Viromics Step 6: Abundance Estimation
  • GitHub

Overview

Unlike 16S sequencing or even shotgun metagenomic tools like MetaPhlAn,, viral abundances aren't directly calculated during their annotation steps.

This is because annotation is performed on a list of representative sequences, which doesn't include any information about where each representative sequence shows up in the dataset.

The abundance estimation, done by CoverM, takes each annotation and aligns it to the original clean reads to see how often it shows up in each sample.
