Overview

The following script will perform a version of the read processing steps covered in the general Metagenomics tutorial. Please refer to the full tutorial for more detailed instructions.

Briefly, raw metagenomic reads usually contain all of the DNA sequences released by the sequencer. This means that there are non-bacterial sequences present (such as gut epithelial cells, if working with gut samples), and there will be some proportion of damaged or otherwise non-useful reads that should be removed.

Run the Code

Part 1: Processing the Samples

This will clean all reads and generate quality reports for each sample.

Note that this is an ARRAY script run PER SAMPLE. Running as sbatch script.sh will run all array values (i.e. all samples); individual array values can be run using sbatch --array=0,1 script.sh, etc.

Be sure to change all file paths to match your system.

Part 2: Generating the quality report

This will combine all the FastQC quality reports and produce a single HTML report file (much easier to parse).

Be sure to change all file paths to match your system.
