Viromics Step 2: Contig Assembly
  • GitHub

Overview

This will assemble the cleaned reads into longer contigs using MetaSpades, assess their quality with Quast, and determine which contigs are circular with MUMmer. This is analogous to typical MAG assembly of bacterial genomes.

Required Software

The following software was used to run the original scripts. Please update as desired.

Disclaimer: Please note that all scripts are designed to be run in Compute Canada, which has some software pre-installed as modules. Compute Canada also uses SLURM to run jobs. Please adjust the code as needed for your system.

Software Version Format used Purpose
MetaSpades 4.2.0 Pre-installed module Assemble contigs from cleaned reads
QUAST 5.2.0 Pre-installed module Assess assembly quality
MUMmer (info not on hand) Pre-installed module Assess read quality
seqkit (info not on hand) Pre-installed module Supporting module with many relevant functions

Installing the Software

No installation is required for the pre-installed modules.

Run the Code

Part 1: Processing the Samples

This will run all required steps of the pipeline.

Note that this is an ARRAY script run PER SAMPLE. Running as sbatch script.sh will run all array values (i.e. all samples); individual array values can be run using sbatch --array=0,1 script.sh, etc.

Be sure to change all file paths to match your system.

Part 2: Contigs per sample

This will count how many contigs are in each sample. It usually doesn't need to be submitted as a job, as it is not computationally intensive - just run directly in the console.

Be sure to change all file paths to match your system.
