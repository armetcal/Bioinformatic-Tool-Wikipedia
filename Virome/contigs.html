Viromics Step 3: Identifying Viral Contigs
  • GitHub

Overview

This identifies viral contigs with DeepVirFinder and VirSorter2, then filters for quality. Any ambiguous hits are validated with CAT. Finally, viral contigs are trimmed and filtered with CheckV in order to remove any lingering non-viral elements. (Since bacteriophages insert themselves into host genomes, it's common to have host DNA flanking the viral DNA)

Step 1: Generate lists of high-confidence and ambiguous hits.

Step 2: Validate ambiguous hits, then apply final trim & filter.

TROUBLESHOOTING:

This tool uses Theano. I don't know much about it, except that it was a pain in the butt to get working properly.

If you're unlucky, one or more of your input files might have an exact multiple of 100 contigs. This will cause something that looks like an error. Example in the .err file: "ValueError: not enough values to unpack (expected 3, got 0)" This is because DeepVirFinder splits the input into batches of 100 contigs, and if your input file is sorted by contig size, all of the final 100 contigs will be filtered out, causing it to try to process an empty batch. The end of the .out file should show "processing line [number]", where the number is equal to the total number of lines in the input file. You can test this with the wc command. Check the output file - if the tail looks normal, then you should be safe.

Part 3: Filter the Clusters

First, we will filter each contig list for length.

Then, we will separate the outputs into high-quality and ambiguous hits using the built-in quality scores from each tool.

The viral criteria are twofold:

  • 1. Length >= 5 kb OR (Length >= 1.5 kb AND circular)
  • 2. One or more of the following:
    • a. DeepVirFinder score >= 0.9 AND p < 0.05

    • b. VirSorter2 score >= 0.9
    • c. Contig present in VirSorter2 output AND (DeepVirFinder score >= 0.7 AND p < 0.05)

Be sure to change all file paths to match your system.

Step 2: Validate ambiguous hits, then apply final trim & filter.

Part 1: Validate ambiguous hits with CAT

WARNING: this script is not well validated compared to the others. Sanity check all outputs.

The Contig Annotation Tool (CAT) is a tool that is partially designed to taxonomically classify organisms that are not well characterized (or characterized at all). This is particularly helpful for viruses, since they are not as well understood as bacteria.

The CAT algorithm involves gene calling, mapping of predicted ORFs against a protein database, and voting-based classification of the entire contig based on classification of the individual ORFs.

This script runs CAT on all ambiguous hits found per sample. If there are no ambiguous hits, it skips the file (no fail).

Note that this is an ARRAY script run PER SAMPLE. Running as sbatch script.sh will run all array values (i.e. all samples); individual array values can be run using sbatch --array=0,1 script.sh, etc.

Be sure to change all file paths to match your system.

Part 2: Trim/filter with CheckV, then apply final quality filter

CheckV performs several functions, including trimming leftover non-viral bases and providing some quality metrics.

Afterward, the processed contigs will be filtered one last time. These filters are based on the idea that viruses are not well characterized compared to bacteria. Specifically, we will retain contigs that either have viral genes OR don't have host genes OR have a high proportion of unknown genes.

Note that this is an ARRAY script run PER SAMPLE. Running as sbatch script.sh will run all array values (i.e. all samples); individual array values can be run using sbatch --array=0,1 script.sh, etc.

Be sure to change all file paths to match your system.

Part 3: Count the remaining viral contigs per sample

Paired with prior outputs, this will let you calculate the proportion of contigs that were viral, the sequencing depth needed to get X unique viral contigs, etc.

The code runs quickly and doesn't usually need to be submitted as a job.
