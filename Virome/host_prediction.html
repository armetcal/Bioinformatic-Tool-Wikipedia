Overview

Most viruses detected using traditional metagenomic sequencng are bacteriophages. Most bacteriophages are specific to one bacterial host. We will use iPHoP, which aggregates the results of several tools to provide a composite host prediction.

iPHoP is a two-step process. First, it computes raw host predictions for each chunk of sequences using six different tools. Then, it aggregates these predictions into final host assignments. It's not smart enough to skip the compute step if classification fails, but each step can be run separately, which we'll do below.

Note: iPHoP is only run on LARGE rep-seqs (>10 kb). This output was produced during the clustering step.

Note #2: When analyzing in R, only the top hit should be used for each virus (somewhat contentious, but currently best practice).
