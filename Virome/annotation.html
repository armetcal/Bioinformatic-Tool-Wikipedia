Annotation by alignment with the MGV database

The MGV database was first published in 2021 by Nayfach et. al with the goal of compiling all known viral genomes. It provides a range of useful outputs: taxonomy, proteins, information about which proteins are considered auxiliary metabolic genes, and whether the virus is predicted to be virulent or not.

There are a few different ways the database can be used. We'll run both:

  • Use MMSeqs to align the rep seqs with the database contigs (taxonomic approach)
  • Use MMSeqs to align the rep seq proteins with the database contigs' proteins (functional approach)
