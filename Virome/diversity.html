Overview

MetaPop is a tool for analyzing viral diversity in metagenomic samples.

It calculates both macrodiversity (alpha and beta) as well as microdiversity (within-sample diversity, such as codon variance).

The following software was used to run the original scripts. Please update as desired.

Installing the Software

Run the Code

Part 1: Map reads to rep seqs

Similar to some of the annotation steps, MetaPop needs to know how often each of the representative sequences show up in each sample's reads. However, it also needs to keep each individual read instead of relying solely on the rep-seqs. This is because MetaPop uses the nucleotide variance to calculate microdiversity.

Be sure to change all file paths to match your system.

Note that this is an ARRAY script run PER SAMPLE. Running as sbatch script.sh will run all array values (i.e. all samples); individual array values can be run using sbatch --array=0,1 script.sh, etc.

Part 2: Split the rep seqs into individual FASTAs

Note: I'm not sure this next step is strictly necessary. If you're able to run Prodigal on the original rep-seq file and generate an equivalent Prodigal output, then that would be easier.

This step will also generate a MetaPop-specific read count file. This is necessary for the next step because MetaPop requires that the count file's sample names match the BAM basenames. MetaPop also only requires the forward read count. Feel free to recode this so that it merely edits the original read count file (from the cleaning step).

Be sure to change all file paths to match your system.

Part 3: Run MetaPop

This part also includes the Prodigal gene calling step - it's computationally intensive, so more appropriate for the higher resources requested here. However, it adds a lot of time to the run. It therefore uses a flag system to avoid re-running this step unnecessarily, where a .flag file is created in a specific location once the Prodigal step finishes. DELETE THIS FILE IF YOU WANT TO RE-RUN PRODIGAL!!

Also note that this takes a long time overall to run. Increase the time as necessary - this was troubleshot with only 30 samples.

Be sure to change all file paths to match your system.
